# PourHouse Life

A temporary landing page for **PourHouse Life**, the travel home of Cassie and David.

The page uses four photographs from our travel archive in a rotating, accessible hero slideshow. It is deployed to GitHub Pages automatically from `main`.

## Local preview

Open `index.html` in a browser, or serve the directory with any static file server.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes the repository to GitHub Pages after every push to `main`.
