# PourHouse Life

A temporary landing page for **PourHouse Life**, the travel home of Cassie and David.

The page uses eight photographs from our travel archive in a rotating, accessible hero slideshow. The slideshow advances every 4.5 seconds and includes pause/play and manual controls. A live countdown marks the October 18, 2026 launch at 8:00 AM Eastern Time.

## Local preview

Open `index.html` in a browser, or serve the directory with any static file server.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes the repository to GitHub Pages after every push to `main`.
